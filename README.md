# Brainux WHACH-A-MOLE for PW-G5200

## 概要

SHARP電子辞書 Brain 上で動作する Linux 環境「Brainux」向けの、もぐらたたきゲームです。
PW-G5200のサブディスプレイで動作します。（他のサブディスプレイ付き機種では動作未確認）  

Brainuxからサブディスプレイ（手書き入力用ディスプレイ）に画面を描画し、タッチパネルによる操作でゲームを楽しめます。

C言語で作成しており、Brainux標準のGCCを使用してコンパイルできます。

### 主な機能

- サブディスプレイへのゲーム画面表示
- タッチパネルによるもぐらたたき操作
- 10秒間の制限時間
- もぐらに当たると10点加算
- もぐらの出現間隔はランダム
- ヒット時に、もぐらの表情を変化させる演出
- STARTボタンによるゲーム開始・再開
- ゲーム終了時のスコア表示

## 動作環境

- SHARP Brain 電子辞書 PW-G5200
- Brainux
- GCC（Cコンパイラ）

本プログラムは、SHARP Brain PW-G5200上のBrainux環境での使用を想定しています。

## 準備

### 1. ソースコードの配置

GitHub 画面右上の [Code]ボタンをクリックして zipファイルをダウンロードし、zipファイルの中にある src/mogura.c をBrainux上の任意のディレクトリに配置します。  

例えば、`~/games/Whack-a-Mole` に配置した場合、次のコマンドでディレクトリに移動します。

```bash
cd ~/games/Whack-a-Mole
```

### 2. コンパイル

GCCを使用してコンパイルします。

```bash
gcc -O2 -Wall -Wextra -o mogura mogura.c
```

コンパイルが正常に終了すると、実行ファイル `mogura` が作成されます。

エラーが表示された場合は、ソースコードの配置場所やコンパイラの環境を確認してください。

### 3. ゲームの起動

次のコマンドでゲームを起動します。

```bash
sudo ./mogura
```

本プログラムは、フレームバッファとタッチパネルのデバイスを使用します。

- 画面デバイス：`/dev/fb1`
- タッチパネルデバイス：`/dev/input/event0`

デバイスへのアクセス権限などの理由により、管理者権限での実行が必要になる場合があります。

## ゲームの遊び方

### 1. ゲームを開始する

画面右上の **START** ボタンをタッチすると、ゲームが開始します。

### 2. もぐらをたたく

画面に現れるもぐらをタッチしてください。

もぐらに当たると10点が加算され、ヒットしたもぐらの表情が変化します。

もぐらは一定の間隔でランダムに出現するため、素早くタッチして得点を獲得しましょう。  
もぐらの出現タイミングを変えたい場合は下記2つの変数の値を変更してください。  
```
   MOLE_INTERVAL_MIN_NS : 次のもぐらが出現するまでの最短の時間  
   MOLE_INTERVAL_MAX_NS : 次のもぐらが出現するまでの最長の時間  
```
この２つの値の間でランダムで次のもぐらの出現時間が決まります。  

### 3. 制限時間

ゲームの制限時間は10秒です。  
ソースコードの GAME_SECONDS の値を変更することでゲーム時間を変更できます。  

制限時間内に、できるだけ多くのもぐらをたたいて高得点を目指してください。

### 4. ゲーム終了・再開

制限時間が終了すると、GAME OVERと最終スコアが表示されます。

もう一度プレイする場合は、画面右上の **START** ボタンをタッチしてください。

## 注意事項

### サブディスプレイについて

本プログラムは、Brainuxのフレームバッファ `/dev/fb1` を使用してサブディスプレイに描画します。

対象のBrain機種やBrainuxの構成によって、フレームバッファのデバイス名やタッチパネルのデバイス名が異なる場合があります。

動作しない場合は、使用している環境のデバイス構成を確認してください。

### タッチパネルについて

タッチパネルの入力は `/dev/input/event0` から取得します。

タッチパネルの座標や入力方式は機種・環境によって異なる場合があります。また、タッチのタイミングによって、入力が認識されないことがあります。

### 他のプログラムとの同時実行

同じサブディスプレイやタッチパネルを使用する別のプログラムを同時に実行すると、画面表示や入力操作に影響する場合があります。

ゲームの表示や操作に異常が発生した場合は、他の関連プログラムが動作していないか確認してください。

### 実行環境について

本プログラムは、Brainux上の特定のデバイス構成を前提にしています。すべてのBrain機種やLinux環境での動作を保証するものではありません。
